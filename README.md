# Tpot_log_analyzer - تحليل سجلات الطعم الإلكتروني

## 📋 وصف المشروع
هذا المشروع يحلل سجلات منصة T-Pot Honeypot (خدمة Cowrie) لكشف حملات Botnet التي تستهدف أجهزة IoT.
تم جمع 81 سجل هجومي بتاريخ 10 سبتمبر 2026، وتم تحليلها لتحديد نمط هجوم Mirai IoT Botnet.

## 🎯 الأهداف
- تحليل سلوك المهاجمين باستخدام إطار MITRE ATT&CK
- تحديد الخدمات المستهدفة (Telnet 93% - SSH 7%)
- تصنيف مستوى الخطورة مع ذكر السبب
- استخراج مؤشرات الاختراق IOCs
- تقديم توصيات أمنية عملية

## 📊 النتائج الرئيسية
- **إجمالي السجلات:** 81 سجل
- **المهاجمين:** 3 عناوين IP (152.32.207.43 مسؤول عن 93%)
- **الخدمة الأكثر استهدافاً:** منفذ Telnet 23
- **الأداة المستخدمة:** Hydra v9.5
- **التوقيع المكتشف:** busybox ECCHI (توقيع Mirai)

## 📁 محتويات المستودع
